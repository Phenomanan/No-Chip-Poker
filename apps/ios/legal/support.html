Support

Need help, found a bug, or want to report a problem? Open an issue on GitHub (please do not include personal details in public posts; the room code and a description are enough).

Getting started

  • Start a table: create a room, share the 6-letter room code, and friends join with it. The host presses Start Hand.
  • Try it alone: on the iOS app tap Start Practice Table to play a full hand against practice players.
  • Dealing: the app does not deal cards. After each round of betting the host deals the flop, turn or river with a real deck and taps the confirm button; then betting continues.
  • Showdown: the host picks the winner(s) and the app pays out the pot(s).

Common questions

  • I lost my connection. Reopen the app; it rejoins your table automatically. If it is your turn the table waits for you, or the host can remove you.
  • Someone is being abusive. Tap the "..." next to their message to report or block them. The host can mute or remove them from Table Settings.
  • Delete my data. Rooms delete themselves 24 hours after their last activity. To have something removed sooner, open an issue with the room code.
  • Is this real-money gambling? No. Chips have no value; the app only keeps score for your game.
